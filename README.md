# Huananzhi-X99H-Hackintosh-EFI
OpenCore config for Huananzhi X99-H motherboard (B85 chipset)

# Моя конфигурация:
 * Intel Xeon E5-2680 v4
 * AMD Radeon RX 6600 8GB
 * Huananzhi X99-H
 * 32 Gb DDR4 UDIMM

# Должно работать на macOS от Ventura до Tahoe

# Тестировал на:
 * macOS 15.x Sequoia
 * macOS 26.x Tahoe

# Параметры BIOS
 * Не требуется Above 4G Decoding
 * VT-d выключен
 * CSM выключен
 * Работает с MSR Lock

# Баги
 * Не работает встроенная аудиокарта. Звук с видеокарт или с внешних USB аудиокарт работает

 * В остальном всё работает стабильно

# ***‼️ ВАЖНО ‼️***
