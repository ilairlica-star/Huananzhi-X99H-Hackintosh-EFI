# Huananzhi-X99H-Hackintosh-EFI
OpenCore config for Huananzhi X99-H motherboard (B85 chipset)

# Моя конфигурация:
 * Intel Xeon E5-2680 v4
 * AMD Radeon RX 6600 8GB&
 * Huananzhi X99-H
 * 32 Gb DDR4 UDIMM

# Должно работать на macOS от Ventura до Tahoe

# Тестировал на:
 * macOS 15.7.1 Sequoia
 * macOS 15.8.1 Sequoia
 * macOS 26.7.1 Tahoe

# ***‼️ ВАЖНО ‼️***
